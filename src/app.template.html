Installed fonts & local files

Google suggestions apply immediately. For an installed font, enter one name and press Enter. Lists are not supported. Installed families are measured in the browser without font-file access; static fonts are supported. Quote a name to prefer its local version over Google. Fonts available only inside an app, such as Office cloud fonts, may need system installation first.

File imports require a variable weight axis. Choose a Google family/link/CSS embed, or paste a direct HTTPS WOFF, WOFF2, TTF or OTF URL (16 MB maximum). The font host must allow CORS, including access from local files. All processing is done in your browser; no data is sent to a server. A usable width axis enables independent width fitting.

Font details

The recipe

Width adjusts wdth in fitted and built-in small-caps when available; otherwise it adjusts only the horizontal-scaling row and export (scaleX, where 1 means unchanged width). Automatic height, weight, and tracking are fitted separately for each recipe; the controls show the selected fitted recipe’s values. Height changes apply to the fitted small-caps. Small-cap weight applies to fitted small-caps; Built-in uses the text weight. Manual tracking also applies to Built-in. Full-size initials stay unchanged. After initial adjusts the gap in all small-caps previews and exports; it is unused in all-small-caps mode. Tune weight and tracking at reading size on your target OS and browser: hinting and antialiasing can change apparent darkness.

How fonts compare

CSS-only calibration: actual wght/wdth axes, no geometric stretching. Green squares = serif; orange circles = sans-serif. Roboto Mono is grouped by its sans-serif letterforms. Reference type and width-axis availability are listed in the table and tooltips. Numbers identify table rows. Optical designs use each font’s own endpoint, not a shared numeric size; base width and other axes stay at defaults. These measurements are embedded and work offline; extra font files are not bundled.

Orange circles: sans-serif. Green squares: serif. Focus a point and use arrow keys to explore; Home and End move to the first and last point. Read the measurements table.
